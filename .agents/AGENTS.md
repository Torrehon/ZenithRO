# Reglas del Proyecto

- **No Compilar:** Bajo ninguna circunstancia se deben ejecutar comandos de compilación o construcción (como `msbuild`, `make`, o similares) en este proyecto. Las tareas del agente deben limitarse únicamente a realizar modificaciones de código y archivos de configuración. La compilación y verificación de la compilación serán manejadas exclusivamente por el usuario.
