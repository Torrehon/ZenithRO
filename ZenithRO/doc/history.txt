== History =========================================================

[Version 3.5.0 - 2026-07-04]
+ Added crash guard to display mode enumeration to avoid crashes from incompatible graphics drivers and malfunctioning graphics enhancements/wrappers.
! [snippets::dx7enum] Mitigated `dxgi.dll` side-loading vulnerability in DirectX 10 and newer.
! [snippets::w32ddraw] Mitigated `dxgi.dll` side-loading vulnerability in DirectX 10 and newer.
! [snippets::w32d3d9] Mitigated `dxgi.dll` side-loading vulnerability in DirectX 10 and newer.
! [snippets::w32ui] Fixed loading tool tips could corrupt other UI elements or crash.

[Version 3.4.0 - 2025-07-07]
+ Added support for /minimap, /mineffect, /emblem and /showshop.
+ Added support for ROExt 2024.12.13.0 (in addition to the previous ones).
* Configurable setup-imposed limits on resolution are now an array to specify limits per DirectX version.
  * Updated default minimum width for DirectX 7 to 0 (no limit).
  * Updated default minimum width, maximum width and maximum height for DirectX 9 to 0 (no limit).
  # Old non-array syntax continues to work for all DirectX versions that aren't overriden per-version.

[Version 3.3.0 - 2025-02-09]
+ Added support for disabling specific DirectX versions [suggested by Wizzello].
* Updated Spanish localization [csnv].

[Version 3.2.1 - 2024-07-27]
+ Added command line switch /firstrun.
* Updated the icon set to not rely on RO assets.
* D3D9 is no longer needed to run.
- Removed telemetry.

[Version 3.1.1 - 2024-04-28]
* Renamed the test client to avoid name collision with an actual project.
* Updated Brazilian Portuguese translation [drigoguille].

[Version 3.1.0 - 2023-11-18]
+ Added support for ROExt 2018.6.10.0 (in addition to the previous one).
* Updated missing translation bits in French, Spanish, Brazilian Portuguese and Russian with DeepL.
! Fixed resolutions other than the first on the list would not work correctly (since 3.0.0).
! Fixed settings' saving order.
! Fixed values of DX9 settings when DX7 is selected.
! Fixed tool tips not working in ROExt tabs.
- Removed settings 'VooDoo3 graphics card' and 'Disable hardware-accelerated graphics'.

[Version 3.0.0 - 2023-10-22]
+ Added support for DX9 (available from kRO RAG/ZERO 2023-09-06).
* Enabled some previously disabled sound settings in Lua. While there is no UI for them, the official setup application still writes these, so maybe the client also still uses them.
! Fixed ROExt tab layout did not align with the other tabs.
! Fixed crash when retaining non-numeric Lua config values.
- Removed REG engine.

[Version 2.18.0]

[Version 2.17.0]
+ Added support for live-testing the currently selected graphics settings.
* Improved UI/UX design guideline compliance.
* Improved high DPI support.
* Splitted releases into 'legacy' (registry), 'default' (Lua) and 'zero' (Lua for Zero). Run-time switching is no more, because it was confusing and led people into spectacular trouble-shooting fails.
! Fixed ROExt's code page list could be empty due to errors in code pages 1147 and 20949.
! Fixed text-clipping with German UI.
! Fixed info/error icons not showing on MessageBox*s.
