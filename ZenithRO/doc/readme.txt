== About ===========================================================

Enhanced alternative for the default game setup application shipped
with every RagnarokOnline installation. Comes in several languages,
is free of cost and works on every 32-bit and 64-bit Microsoft*
Windows* platform.

== Known Bugs & Issues =============================================

 - [aavc] Is not safe for computers running Anti-Virus products
   incorporating Parametrically Averaging Inferences (PAI) as part
   of their detection routines.

== Requirements ====================================================

 - Operating system:
    - Windows 95 (may work, not actively tested)
    - Windows 98/ME
    - Windows NT (may work, not actively tested)
    - Windows 2000/XP/Vista/7/8/8.1/10/11
      > Except Windows Server Core (and similar configurations)
      > Except Windows RT
      > Except Windows S (and similar configurations)
    - Note: Requires at least DirectX 7 to be installed. Some
      versions may require at least DirectX 9 to be installed.
 - Hardware:
    - 32-bit platform or emulations thereof (for example WOW64)
    - Disk space < 1 MB
    - RAM < 30 MB
    - Keyboard or a pointing device
      > Yes, you can utilize all functionality using the keyboard
      > alone!

== Usage ===========================================================

This software does not require any installation. Copy it into an
existing RagnarokOnline installation.

Changes made to the game configuration are not saved immediately,
but only after clicking OK/Apply. Some installations may require
administrator rights to write the settings. Such need is detected
automatically, no need to always run it as administrator. Clicking
Cancel discards all changes made.

Most settings and buttons show explanations when pointing at them.

== Command Line Parameters =========================================

None of these are supported by the official setup application.

/defaults       Saves settings in the same manner as opening
                OpenSetup and clicking OK. The UI may be shown, if
                it's necessary to elevate to safe the settings.

/firstrun       Opens the UI only when no settings have been
                detected.

== Updating & Removal ==============================================

For updating you have to check the website for newer versions. Just
overwrite the old files with the new ones.

If you no longer want to use the application, delete opensetup.exe,
opensetup.ini, associated docs and any logs. OpenSetup does not
store any user data in the registry (besides RO settings) or
anywhere else.
